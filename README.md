# 九つ石のモリス

3つ並べて相手の石を取り合う、古い盤上遊び「ナイン・メンズ・モリス」をブラウザで遊べます。

- **オンライン対戦**：部屋を作ってリンクを送ると、お互いのブラウザが直接つながって対戦できます（WebRTC／PeerJS）。部屋のデータはどこにも保存されず、対局が終わるか、部屋を作った人がページを閉じると部屋はなくなります。
- **この端末で遊ぶ**：1台で2人対戦、またはCPU対戦（3段階）ができます。

## 公開のしかた（GitHub Pages）

1. このリポジトリに `index.html` を置きます。
2. Settings → Pages を開き、Source を「Deploy from a branch」、Branch を `main` と `/ (root)` にして保存します。
3. 数分後に表示される `https://<ユーザー名>.github.io/<リポジトリ名>/` を開きます。

## 補足

- 接続の仲介には PeerJS の無料公開サーバー（0.peerjs.com）を使います。混雑時はつながりにくいことがあります。
- 学校や会社のネットワークなど、直接接続が制限されている環境ではつながらない場合があります。
- PeerJS はバージョンを 1.5.5 に固定し、改ざん検出（SRI）を付けて読み込んでいます。
